The games

Six games on one engine. Only the first is being ported — the rest are here because they share the engine, so what the port learns about one usually applies to the others.

Why the others matter

Every one of these runs on Alchemy, the same engine, with the same archive format and the same object model. A structure worked out by staring at Imaginators — which shipped with its symbols intact — is usually the same structure Spyro’s Adventure uses with the names stripped out. The later games are documentation for the earlier one.
