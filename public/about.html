About

Skylanders: Spyro's Adventure shipped on more platforms than people usually remember — Wii, Wii U, PS3, Xbox 360, PC, Mac, 3DS — built by more than one studio, on more than one engine. The Wii U version, released only in Japan, runs on the same Toys for Bob engine as the original Wii release, on hardware that's since been left behind by almost everyone except a small, dedicated reverse-engineering community.

Arkchemy exists to keep that specific version playable, by porting it properly rather than emulating it. A static recompiler reads the game's real compiled PowerPC code once, ahead of time, and translates it directly into portable C — the same technique used by projects like N64: Recompiled — so what actually runs on the Switch is native ARM64 code, not a PowerPC CPU being emulated frame by frame.

How it's built

The work splits into three independent pieces, each its own repository:

  • conquertron — the recompiler itself: disassembly, function-boundary recovery, and C code generation from the real Wii U binary.
  • jouster — everything the recompiled code needs to actually run on a Switch: thread/memory primitives, file I/O redirected to the SD card, and a from-scratch reimplementation of the graphics layer.
  • blaster — Python tooling for the game's own file formats, built up alongside the recompiler as a side effect of needing to actually read and understand the data the recompiled code operates on.

None of this happens in a vacuum. This project leans hard on the public reverse-engineering work the wider Skylanders community has already done and continues to do — file format documentation, portal protocol writeups, and a lot of patient, first-hand engine knowledge shared freely in community spaces. See CONTRIBUTORS.csv for the people whose work this project is built on top of.

What this isn't

This isn't a way to play Skylanders for free. Arkchemy ships no game assets, no game code, and no copy of the game itself — every tool here operates on a copy you already legally own, exactly the same way a save editor or a texture pack injector would. See the license for the exact, non-negotiable terms this is released under: no sales, no paywalls, and no redistribution of anything produced by running these tools against the game.
