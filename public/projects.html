Projects

Three repositories, each doing one job. They're built to be used independently — blaster in particular is just as useful to anyone modding the game by hand, whether or not they care about the recompiler at all.

conquertron

A PowerPC-750 → C static recompiler, purpose-built against the real Wii U binary rather than a general-purpose target. It disassembles the game's own machine code, recovers real function boundaries where symbols were stripped, and emits portable C per function — condition-register semantics, byte order, and floating-point behavior all translated deliberately rather than approximated, since a physics or gameplay desync would be a real regression, not a cosmetic one.

This is the piece that doesn't exist anywhere else for Wii U specifically. Comparable projects (N64: Recompiled, Zelda 64: Recompiled) had an existing decompilation to build on; this one is built directly from the compiled binary.

jouster

Everything the recompiled code assumes is already there. Cafe OS's own thread, memory, and file APIs get reimplemented against libnx equivalents; GX2 draw calls get intercepted and reinterpreted rather than passed straight through, since the Switch's own graphics API doesn't speak GX2 natively. A Portal of Power can be read three ways — a real USB portal, a folder of figure dumps, or a Joy-Con's own NFC reader — with the UI built around whichever one's connected.

This is also where the actual `.nro` gets packaged for real hardware, and where most of the boot-time debugging work has happened — tracing exactly where the recompiled game's own execution diverges from what real Wii U hardware would do, one hardware test at a time.

blaster

A standalone toolkit for the Alchemy engine's own file formats — reading and rewriting .igz object archives (the engine's real "memory image" save format, objects stored roughly as they'd appear in RAM, fixed up on load), extracting field names and types directly out of the compiled reflection data with no running game required, and format-specific utilities like the Wii→Wii U audio transplant pipeline built for the English translation work.

Grew out of needing to actually understand these formats to build the recompiler and runtime — kept separate because the format-editing side is useful to modders who have no interest in the recompiler itself.

Status

Actively in development. The recompiler core and Switch runtime both build and boot the real recompiled binary on real Switch hardware; current work is tracing and fixing the remaining boot-time divergences from real Wii U behavior, one hardware-confirmed bug at a time, before graphics and gameplay work can meaningfully begin.
