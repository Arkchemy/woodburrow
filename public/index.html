What this is

Arkchemy is porting Skylanders: Spyro's Adventure to the Nintendo Switch. The console it shipped on is out of production, the online services behind the series are gone, and the discs will not read forever. This is an attempt to keep the game playable.

The work is a static recompiler: the game's PowerPC code is translated to C, then rebuilt for ARM64. Nothing is emulated at runtime.

The games

All six run on the same engine, so most of what the first port needs the others need too.
