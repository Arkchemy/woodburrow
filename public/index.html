About

Arkchemy is a small organization building open, permission-required tools that reverse-engineer, preserve, and static-recompile older Skylanders titles onto modern hardware — starting with Skylanders: Spyro's Adventure (Wii U) running natively on Nintendo Switch, no emulator involved.

The name is a double reference: Ark is the real internal engine namespace Toys for Bob's games are built on (igArkCore, arkRegister, and so on throughout the actual compiled code), and Alchemy is the real, public name of that same engine. Put together, it's the same move as "Pretendo" borrowing from "Nintendo" — a name that points directly at the real technology underneath it.

Everything here runs against a copy of the game you already own. Nothing here hosts, sells, or redistributes Activision's assets or code — see the license for the exact terms.

Highlighted Projects

conquertron

The recompiler core. Translates the game's real PowerPC machine code into portable C, function by function, straight from the original Wii U binary — no interpretation at runtime, just compiled native code.

jouster

The Switch side of the port: the runtime that hosts the recompiled game, plus a from-scratch reimplementation of the Cafe OS system calls, memory model, and graphics layer the original game expects to find underneath it.

blaster

Standalone Python tooling for working with the game's own file formats directly — reading and rewriting .igz object archives, extracting field schemas straight out of the compiled reflection data, and other utilities that grew out of the recompiler work.
