Skylanders: Spyro’s Adventure, rebuilt to run natively on the Nintendo Switch.

A fan preservation project. The Wii U game’s code is translated, instruction by instruction, into C and compiled for the Switch. No emulator runs underneath it.

Where it stands

Six walls between a disc and a playable game

Each one has to fall before the next can even be tested. None is ever marked finished: working means working so far, and a stage that looks done can still be hiding bugs.

    How it works

    Not an emulator

    An emulator pretends to be a Wii U while the game runs. This does the work once, ahead of time: the game’s own instructions become ordinary C, and that C is built like any other Switch program.

    1. Your copyThe Wii U game you already own. Nothing from it is shipped by this project.
    2. conquertronReads the game’s PowerPC code and writes out 1.45 million instructions as C.Recompiler
    3. jousterCompiles that C for the Switch’s ARM64 chip, with a stand-in for the Wii U’s operating system.Switch build
    4. The SwitchA native homebrew app. Every result on this site was measured on real hardware.
