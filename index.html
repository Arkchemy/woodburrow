Technical Architecture

Core components powering the static recompilation pipeline.

PowerPC → C Recompiler

Full static translation of ~20,000 functions from the retail Wii U binary. Uses Capstone for disassembly, emits portable C that passes gcc -fsyntax-only cleanly.

~8.6M Lines Generated 100% Instruction Coverage

CafeOS Runtime Shim

196 of 284 CafeOS imports implemented: real ExpHeap/FrmHeap allocator, callback invocation, pthread-backed OSMutex/OSEvent/OSSemaphore with verified concurrent correctness.

Real Heap Allocators Verified Threading

Switch Native Target

Compiles to native ARM64 homebrew via devkitA64/libnx. No emulation layer — runs directly on Nintendo Switch hardware with full GPU access via NVN/deko3d.

devkitA64 / libnx Hardware Verified
