Project Status

Milestones

A condensed, factual log of verified progress. Full technical detail — including every real bug found and fixed along the way — is in the repository's README.

1

PowerPC → C recompiler core

A working static recompiler translating PowerPC instructions into portable C, verified end-to-end against known-correct output on both host and QEMU-ARM64.

2

First hardware-verified homebrew build

Recompiled test programs confirmed running correctly on real Switch hardware — not just emulation — including indirect calls and rodata addressing.

3

Full retail binary recompiled

Every one of the real game's ~19,600 functions compiles with zero unhandled instructions, validated against three independent real-world Wii U homebrew binaries along the way.

4

CafeOS runtime shim layer

Real filesystem I/O, heap allocation, threading, and synchronization primitives — genuine multi-threaded execution backed by host pthreads, not stubs.

5

GX2 → deko3d rendering

All 284 real GX2 graphics imports have a callable shim; render-state, samplers, and buffer management confirmed on real hardware. Shader translation and draw calls remain the largest open problem.

6

Complete game links and boots

The actual, complete recompiled game — not a test program — links and runs on real hardware via its real entry point. Post-boot correctness work is ongoing; see the repository for current status.

Project development notice. Bramble is under active architectural development. Downloadable builds are early developer test programs used to validate the recompiler — not the finished game. This site reflects the project's real, live state; nothing here is aspirational marketing copy.

Privacy Policy

Last updated: August 20, 2026

Zero local telemetry. The offline Software collects zero telemetry or user data. This policy governs this website itself and the opt-in, not-yet-released "Skylanders Online" network service.

01 Data Controller

The Bramble Project is the data controller for personal data processed through this website and, in future, Skylanders Online network services. Contact: aaron@aaronworld.uk. The offline Software runs entirely on your own device and transmits no data to any server.

02 The Offline Software

  • No analytics, crash reports, or usage statistics are collected by the recompiler or anything it produces.
  • No network connections are initiated by the Software itself.
  • Figure data read from a Portal of Power or local dump never leaves your device.

03 This Website

The Downloads and License pages call the public, unauthenticated GitHub API directly from your browser to display live repository statistics, release listings, and license text — no personal data is sent as part of those requests. This site sets no cookies and runs no analytics or tracking scripts of its own.

A planned, not-yet-released, opt-in multiplayer layer. Intended scope: account basics (email, display name, hashed password), transient session state, and IP addresses kept only as needed for connection routing and abuse mitigation. No data is ever shared with Activision, Microsoft, Nintendo, or any other rights holder, and nothing is sold.
